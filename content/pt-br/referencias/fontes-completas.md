# Todas as fontes públicas, por área

**Como foi feito:** busca na web + abertura de cada URL para confirmar que há texto substancial (não página de compra, não resenha vazia, não PDF pirata). Links atrás de paywall ou que retornaram 403/404 ficaram de fora e estão listados no fim.

**Uso previsto:** alimentar um notebook no Google NotebookLM e servir de base para um guia em `.md` (possível GitHub Pages).
