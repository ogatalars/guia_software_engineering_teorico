# Designing Data-Intensive Applications — guia de leitura

> [!NOTE] Em uma frase
> Todo sistema que guarda e move dados faz escolhas entre confiabilidade, escalabilidade e facilidade de manutenção; este livro mostra quais são essas escolhas e o que cada uma custa.

> [!WARNING] Em construção
> Este guia está sendo escrito seguindo o template do projeto (para quem é, como o livro se organiza, como ler, o que levar, um guia por capítulo). Enquanto isso, as [fontes públicas verificadas](fontes.md) já estão disponíveis.

## Plano de páginas
Um guia por capítulo, 12 no total, nas três partes do livro: fundamentos de sistemas de dados (1–4), dados distribuídos (5–9) e dados derivados (10–12).
