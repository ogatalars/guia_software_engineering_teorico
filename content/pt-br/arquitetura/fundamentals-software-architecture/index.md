# Fundamentals of Software Architecture — guia de leitura

> [!NOTE] Em uma frase
> Não existe arquitetura certa, só trade-offs; o trabalho do arquiteto é identificar quais características o sistema precisa ter, escolher o estilo que as atende e registrar o porquê.

> [!WARNING] Em construção
> Este guia está sendo escrito seguindo o template do projeto (para quem é, como o livro se organiza, como ler, o que levar, um guia por capítulo). Enquanto isso, as [fontes públicas verificadas](fontes.md) já estão disponíveis.

## Plano de páginas
Parte I (pensamento arquitetural, modularidade, características arquiteturais), Parte II (visão geral dos estilos, monolitos, microsserviços e event-driven, comparação) e Parte III (decisões e ADRs). Oito páginas.
